## 🧠 [Biblioteca Teórica de Apoyo (Explicada por IA)](./EjercicioPracticos-AI/TeoriaExplicadaPor-IA/README.md)

Guías diseñadas para afianzar conceptos, entender el porqué de cada línea y evitar el bloqueo al escribir código:

1. [**00. Visión General del Profe**](./EjercicioPracticos-AI/TeoriaExplicadaPor-IA/00_vision_general_que_quiere_el_profe.md): El hilo conductor pedagógico de las clases.
2. [**01. Fundamentos y Operadores**](./EjercicioPracticos-AI/TeoriaExplicadaPor-IA/01_fundamentos_operadores_y_entrada_salida.md): Diccionario de inglés, todos los operadores y puente con Python.
3. [**02. POO Esencial**](./EjercicioPracticos-AI/TeoriaExplicadaPor-IA/02_poo_clases_objetos_new_this_y_encapsulacion.md): Qué hace `new`, qué hace `this.` y encapsulación.
4. [**03. Relaciones y Excepciones**](./EjercicioPracticos-AI/TeoriaExplicadaPor-IA/03_relaciones_entre_clases_y_control_de_excepciones.md): Asociación, Agregación, Composición y `try-catch-throw`.
5. [**04. Herencia y Casos Reales**](./EjercicioPracticos-AI/TeoriaExplicadaPor-IA/04_herencia_polimorfismo_static_y_casos_reales.md): `static`, `super`, `@Override`, y desgloses de `empleado.java` y `garaje.java`.
6. [**05. Cómo Empezar desde Cero**](./EjercicioPracticos-AI/TeoriaExplicadaPor-IA/05_como_empezar_desde_cero_sin_bloquearse.md): La Regla de los 4 Pisos para no bloquearte ante un archivo vacío.

## ⚙️ Guía Rápida de Compilación y Ejecución (Consola)

Para compilar y ejecutar cualquier clase desde la raíz del proyecto:

```bash
# 1. Compilar especificando la carpeta de salida:
javac -d bin CursoCompleto250/PrimeraTemario/segundaSemana/practicas/PrimerDia/garaje.java

# 2. Ejecutar la clase (indicando el paquete completo):
java -cp bin CursoCompleto250.PrimeraTemario.segundaSemana.practicas.PrimerDia.garaje
```
