# Matricula escolar

Una escuela gestiona cursos cada curso lo imparte un profesor y tiene varios alumnos matriculados.

De cada matrícula se guarda la fecha y la nota final. Los alumnos pueden matricularse y darse de baja de un curso.

- Identifica las clases candidatas y justifica las que descartes.

- Para cada clase propone al menos dos atributos y un método.
